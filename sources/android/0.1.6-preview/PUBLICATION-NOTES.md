# Public corresponding source: android 0.1.6-preview

This is the complete per-platform release source tree, not a merge of Windows and Android. The source/ tree, native source, generated interfaces, dependency locks, licences and compiled public configuration remain byte-identical to the original release source archive.

Ancillary publication changes only:
- `source/flutter/ios/Flutter/flutter_export_environment.sh`: omitted generated iOS-only environment/path file; regenerated by Flutter and unused by this Windows/Android release
- `source/flutter/ios/Flutter/Generated.xcconfig`: omitted generated iOS-only environment/path file; regenerated by Flutter and unused by this Windows/Android release
- `xixi-build-support/Build-AndroidPreview.ps1`: personal Python default replaced with PATH application discovery
- `records/bridge-generation.json`: provenance-only project absolute paths replaced with ${PROJECT_ROOT}; hashes and interface records retained

PUBLICATION-FILES.json records both hashes for every original entry. Python is resolved from PATH; Android also accepts -PythonPath. Generated iOS path files are unused by these release targets and can be regenerated. ${PROJECT_ROOT} in provenance is a display placeholder, not an application configuration change.

Public server addresses/public keys and the previous LAN migration profile are intentionally retained because they are assets compiled into the original program. They are not credentials. No runtime directories, passwords, private keys, signing materials or installed-device state are included. Rebuilding still requires the fixed toolchains and project layout documented in the included build files.
