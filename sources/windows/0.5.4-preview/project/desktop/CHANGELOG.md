# Windows 预览版记录

## 0.5.4-preview · 2026-10-07

- 默认 ID 服务改为 `videopmt.com:24443`，中继为 `videopmt.com:21117`，公钥和端口保持；同一服务换主机可保持客户端域名配置。
- 仅完整匹配原内置 `64.176.235.139:24443` 或历史 `:443` 地址、中继、公钥且没有自定义 API 时迁移；自定义服务器保持。设备列表保留旧分组并合并至域名分组，相同 ID 保留当前名称，已迁移旧分组中的删除不重新导入。
- Windows 自有公开资产、构建契约、编译后资产及对应源码 ZIP 一致核验；原生 DLL 保持固定官方版本，界面布局不变。
- 本次先生成和验证安装包，安装、本机启动及迁服后的手机互控留待主代理安排，构建自检不作为联测结果。

## 0.5.3-preview · 2026-10-06

- 默认 ID 服务改用 `64.176.235.139:24443`；NAT 测试使用原生相邻端口 `24442`，中继保持 `64.176.235.139:21117`，公开公钥保持不变。网站 HTTPS 使用 `443`。`21115`／`21116` 在当前 Windows 网络链路的 TCP 测试失败，因此未作为本版发布配置。
- Windows 构建使用本目录公开配置资产，分发核验绑定编译后资产；不依赖或修改手机的构建默认资产。
- 完整匹配旧内置 `64.176.235.139:443` 地址、中继和公钥时迁移至新端口；自定义服务器不变。已保存设备按新旧内置服务分组合并，相同 ID 保留当前分组名称，旧记录保留，写入失败不提交迁移标记。
- 使用自行编译的 Flutter AOT、Windows runner 和包内固定原生引擎，安装程序及完整对应源码随发布提供。
- 本次为测试发布；安装程序自检和离线包核验不代表新版远端画面、输入或跨网络联测通过。

0.5.2-preview 的原发布目录与源码包保留。
