# 独立客户端交付目标

用户于 2026-10-04 明确要求以完整软件为目标，先构建两个可安装的产品，再联测，不再要求用户单独安装或先打开 RustDesk。

- Windows：一个西西远程安装包，内部包含所需原生远控引擎与自己的可执行产品入口、设置及卸载流程。
- Android：一个西西远程 APK，内部包含所需引擎，自己的设备和共享入口；与 Windows 一样内置公网配置。
- 使用路径：安装并打开，输入对端 ID，点连接。允许必要的系统权限、对端接入确认及密码验证，但不要求填写服务器或操作另一款应用。
- 权限：普通关闭再打开时保留可持久化的授权；采集会话、进程终止、系统重启和厂商限制分别核验。不能把系统强制要求的录屏确认伪装成永久授权。
- 外观：共用已选银白钴蓝色系与按钮材质，电脑和手机分别设计布局。电脑使用横向工作区、持久左侧导航和设备表格，不能直接套手机首页或底部导航；逐项验证按钮、弹窗、小窗口和缩放。
- 验证：无官方 RustDesk 安装/服务时验证 Windows 包自己的原生引擎加载、编号读取、配置内置及启动。静态/本机检查与远程画面、输入、不同网络和后台验收分开记录。
- 交付记录：明确实际安装产物版本、完成项、尚未完成项与用户回来后的最短联测步骤。没有通过实机的能力不标为通过。

技术允许使用并随产品分发开源引擎库，保留许可和对应源码。外部独立 RustDesk 安装不再是产品前置条件。此前 WinForms 面板依赖官方安装服务的模式不能作为该目标的交付成果。
